```bash

python -m dfxai.rl.train_es_hybrid --kind gating --rl-ckpt results/es/ckpt_seed11_gen00300.npz \
```

## 3. 학습 중 이미 보인 것 (해석 때 참고, 아직 결론 아님)

| 계열 | 시드 | 진단값 (1 → 25 → 100 → 200세대) | 200세대 표준편차 | 적합도 (초기 → 최종) | 소요 |
|---|---|---|---|---|---|
| RES \|δ\| | 0 | 0.011 → 0.040 → 0.044 → 0.226 | 0.057 | ≈ −1.7 → 13.5 | 42분 |
| RES \|δ\| | 1 | 0.023 → 0.040 → 0.147 → 0.199 | 0.046 | ≈ 7.6 → 9.8 | 44분 |
| RES \|δ\| | 2 | 0.008 → 0.039 → 0.072 → 0.159 | 0.038 | ≈ 3.9 → 5.5 | 27분 |
| GATE g | 0 | 0.494 → 0.368 → 0.280 → 0.369 | 0.029 | ≈ 0.2 → −1.5 | 14분 |
| GATE g | 1 | 0.491 → 0.494 → 0.527 → 0.583 | 0.051 | ≈ −4.3 → 4.5 | 44분 |

* **잔차형은 붕괴하지 않았다.** δ 가 0 에서 출발해 200세대에 보정 허용폭(1.0)의 16–23% 를 쓰고,
  적합도는 세 시드 모두 올랐다(시드 2 는 100세대까지 −11 로 처졌다가 5.5 로 회복). 시드 간 편차가
  크므로 결과 절에서 3시드 평균 ± 범위로 쓴다.
* **게이팅형은 0/1 로 굳지는 않았지만 거의 상수다.** 두 시드 모두 g 의 상황별 표준편차가 0.03–0.05
  에 그친다. 즉 게이트가 "언제 규칙, 언제 학습"을 가르는 대신 **고정 α ≈ 0.37 또는 0.58 의 선형
  혼합에 가깝게** 수렴했다. 적합도도 낮다(시드 0 은 초기보다 나빠짐). 본평가에서 이 두 조건이
  `HYB-s11-b300-a0.50` 과 비슷한 점수·D\* 를 내면 "학습된 게이트도 선형 혼합과 다르지 않았다"가
  정직한 결론이다. 시간이 남으면 게이트 입력에 상황 특징을 더 주거나 σ 를 키워 한 번 더 시도할 수
  있으나(설계안 7절의 두 번째 위험), 제출 일정상 **결과를 그대로 보고하는 쪽을 권한다.**
