# 논문 골격 — 공중전 인공지능 모델의 설명가능성과 전투성능 상관관계 분석

이 문서는 **원고를 쓰기 위한 설계도**입니다. 각 절에 무엇을 주장하고, 어느 표·그림이
그 주장을 받치는지, 어떤 반론을 미리 막아야 하는지를 적었습니다. 숫자는 전부
`paper/results_auto.md` 에서 가져오십시오(실험을 다시 돌리면 그 파일이 갱신됩니다).

권장 분량은 대회 규정을 따르되, 방법 : 결과 : 논의 = 3 : 4 : 3 정도가 적당합니다.
서론은 짧게, 한계는 결론보다 앞에 두십시오.

## 0. 한 문단 요약 (초록 초안 재료)

* **문제.** 공중전 AI 는 성능이 높을수록 사람이 이해하기 어려워진다는 통념이 있으나,
  같은 환경·같은 잣대로 이를 측정한 연구가 드물다.
* **방법.** 1대1 기총 도그파이트 시뮬레이터에서 규칙 기반(행동트리 3종)·학습 기반
  (진화전략으로 학습한 신경망)·혼합(혼합계수 α) 정책을 **동일 관측·동일 지령공간**에서
  비교했다. 설명가능성은 행동 로그에 결정트리 대리모델을 적합해 목표 충실도에
  필요한 **최소 깊이 D\***로 정량화했고, 규칙 준수는 하드덱·과G·최소이격 위반율로 쟀다.
* **결과 (2026-09-14 본실험, 67조건·26,800교전·학습 시드 5).**
  성능과 D\* 사이에 **상관이 없다**(전체 ρ=0.06, p=0.62; 학습 정책만 ρ=−0.02,
  p=0.88). 3시드 시점(n=43)에서는 ρ=0.38(p=0.011)의 약한 양의 상관이 보였으나
  5시드로 늘리자 사라졌다 — 반복 수 부족의 우연이었고, 이 사실 자체가 방법론적
  메시지다. 학습 예산에 따라 순수 학습 정책의 점수는 단조 상승(ρ=0.85, p<0.0001;
  복제본 0.639 → 300세대 0.750±0.022, BT-v2 0.671)하고 위반율은 감소(0.096 →
  0.045, 전체 ρ=−0.37, p=0.002)했지만, D\* 는 단조가 아니라 **학습 초기(100세대)에
  급등한 뒤 완만히 내려오는 산 모양**이었다(2 → 8.2 → 7.8 → 7.4, 시드 간 표준편차
  4\~5.5; F(4) 0.975 → 0.929 → 0.933 → 0.933 로 같은 형태). 혼합 정책(α=0.25\~0.75)은
  같은 예산에서 순수 학습 정책보다 D\* 가 높았다(11\~17, 대부분 절단) — 두 정책을
  섞은 행동은 어느 한쪽보다 규칙으로 기술하기 어렵다. BT 3종 안에서는 안전규칙을
  넣은 v3 가 위반율 0 대신 점수를 크게 내주었다(0.671 → 0.329).
* **같은 예산, 다른 전술.** 300세대 순수 학습 정책 5개는 점수가 비슷(0.729\~0.785)
  하지만 전술이 갈렸다: 시드 0 은 한 번 스치듯 쏘고 이탈해 시간종료 HP 우위로
  이기는 '치고 빠지기'(격추 2%, WEZ 0.3 s, D\*=3), 시드 1 은 끝까지 붙는 '추격 격추'
  (격추 35%, WEZ 1.9 s, D\*=17 절단); 나머지 셋은 그 사이(격추 6\~14%, D\* 5\~6).
  격추 비율이 높을수록 D\* 가 크다. 설명가능성 차이는 성능이 아니라 **전술의
  종류**에서 왔다. 논의 절의 핵심 문단. README 6.4 표.
* **의의.** 세 계열을 같은 잣대로 놓고 관계의 **형태**를 보였다: 트레이드오프는
  관측되지 않았고, 설명 비용은 성능이 아니라 학습 단계와 전술 유형에 좌우된다.
  절대 순위가 아니라 관계의 형태가 기여이다.

## 1. 서론 (1쪽)

1. 배경: 공중전 AI(AlphaDogfight 등) 의 성능 향상과 군 운용상 설명·검증 요구.
2. 문제 제기: "설명 가능한 모델은 약하고, 강한 모델은 설명 불가"라는 통념은
   측정된 사실인가, 인상인가.
3. 연구 질문 세 가지
   * RQ1. 규칙 기반·학습 기반·혼합 모델의 전투성능과 설명가능성 사이에 어떤 관계가 있는가?
   * RQ2. 학습 예산(학습량)이 늘어날 때 두 축은 어떻게 함께 움직이는가?
   * RQ3. 규칙 준수(안전 제약)는 이 관계에서 어떤 위치에 있는가?
4. 기여 요약: (i) 세 계열에 동일 적용되는 설명가능성 지표, (ii) 진영 교대 짝지은
   평가 설계, (iii) 학습 예산과 혼합계수를 독립변수로 한 2차원 스윕.

## 2. 관련 연구 (0.5\~1쪽)

* 공중전 AI: 규칙/전문가 시스템 → 강화학습(AlphaDogfight Trials, Pope et al. 2021 등).
* 설명가능 AI: 모델 내재적 설명(트리, 규칙) vs. 사후 설명(SHAP, LIME). 사후 설명은
  모델 계열 의존적이라 **계열 간 비교 잣대로 부적합** → 대리모델 충실도(surrogate
  fidelity; Ribeiro 2016, Bastani 2017 VIPER 등)를 채택한 근거.
* 성능–해석가능성 트레이드오프 논쟁(Rudin 2019 "Stop explaining…" 은 트레이드오프가
  항상 존재하지는 않는다고 주장) → 본 연구는 "특정 과업에서 실측"으로 위치.
* 행동트리(BT) 의 게임/로봇 분야 활용, 하이브리드(규칙+학습) 제어.

## 3. 방법 (3쪽)

### 3.1 교전 환경
* 3자유도 점질량 F-16급 모델, 명시적 오일러 0.05 s, 제어주기 0.2 s, 교전 120 s.
* 기총 WEZ: 사거리 120–1,200 m, 명중 원추 3°→10° 선형 확대, 25 HP/s.
* 승패 규칙(격추·지면충돌·공중충돌·시간종료), 초기조건 범위.
* **표: 부록 A** (config 스냅샷). 본문에는 핵심 값만.
* 한계 선언: 받음각·실속·탄도 미모사 → "이 모델 범위 안에서 유효".

### 3.2 정책 세 계열
* 공통 인터페이스: 관측 20차원(교전기하) → 지령 3차원(뱅크·하중배수·스로틀).
  **"세 모델이 같은 관측·같은 지령공간"** 이 대리모델 비교 공정성의 근거임을 명시.
* BT 3종: BFM 교범 전술(순수/리드추격, 코너속도, 하드덱 회복, **정면 합류 회피**)만
  사용. 세 버전은 성숙도 사다리가 아니라 **서로 다른 교리**임을 밝힘. **표 M1**
  (노드 수, 트리 구조). 합류 회피 노드를 넣게 된 경위(충돌 45\~53% → 3\~10%)는
  README 9.1 — 방법 절에 한 문단으로.
* 학습 정책: MLP 20-32-32-3. **BT-v2 행동 복제로 초기화**(16만 샘플 회귀, 뱅크
  R² 0.95) 후 OpenAI-ES 변형(미러 샘플링, 순위 정규화, σ 0.05, lr 0.01, pop 32,
  후보당 8교전, **갱신 수용 검사**)으로 미세조정. 포텐셜 기반 셰이핑(Ng et al.
  1999 — 최적정책 불변). 체크포인트 0(복제본)/100/200/300 세대 = 학습 예산 축.
  α=1.0 은 MLP 만 실행하는 블랙박스라는 정의는 유지됨.
  **설계 이력을 반드시 쓸 것**: (1) 1차 적합도는 원거리 회피로 수렴(보상 해킹),
  (2) 적합도를 고쳐도 무작위 초기화에서는 여전히 회피 — 교전 시도의 기대 손실이
  회피보다 커서 ES 탐색이 실패, (3) 복제 초기화로 해결했으나 기존 ES 갱신이
  무작위 행보로 복제본을 지움, (4) 수용 검사로 해결. README 9.2\~9.3 / shaping.py 상단.
  심사위원이 가장 좋아하는 종류의 정직한 기록입니다.
* 이 설정이 논문에 주는 이점: 예산 0 에서 학습 정책은 BT-v2 와 행동이 거의 같으므로
  D\* 도 비슷해야 한다(검증 가능한 예측). 예산이 늘며 성능이 갈릴 때 D\* 가 어떻게
  움직이는지가 곧 RQ2 의 답이다. "BT 는 트리라 유리"라는 반론도 같은 행동을 내는
  MLP 의 D\* 로 직접 반박된다.
* 혼합: a = (1−α)a_BT + α a_RL, α 를 관측에 포함해 정책 하나로 전 구간 커버.
  매 세대 α∈{0.25, 0.5, 0.75, 1.0} 을 한 판씩 고정(평가 격자와 동일).

### 3.3 평가 설계
* 상대: 고정 BT-v2(학습 시 사용) 와 BT-v3(**보류 상대**, 학습에 미사용).
* **진영 교대 짝지은 설계**: 같은 시드로 청/홍을 바꿔 2회. 자기대전 검증에서
  0.59 → 0.500 으로 편향 제거(README 5.1). 이 검증을 본문에 **한 문장으로** 넣을 것.
* 통계: 시드 단위 평균 → Wilson CI, 대응표본 Wilcoxon, Holm 보정, 이항검정.

### 3.4 세 평가축
* 성능: 점수(승1/무0.5/패0) **와** 무승부 제외 순수승률 둘 다.
* 설명가능성: D\*(0.95) 주지표, D\*(0.90/0.99)·F(4) 보조. **절단(17) 명시.**
  분산가중 평균, 상수 채널 처리, 행동 포화 함정(README 4.2)을 한 문단으로.
* 규칙 준수: 스텝당 위반율(하드덱 1,000 m·8 G·150 m).

## 5. 논의 (2\~3쪽)

1. **RQ1 답**: 상관 없음(ρ≈0, n=67). 규칙 모델(D\* 1\~5)과 학습 정책(3\~17)의 범위가
   겹친다. BT-v2 가 노드 5개인데 D\*=4 인 이유(연속 arctan2 함수)와, 그것을 복제한
   MLP 가 D\*=2 인 사실을 "트리 구조가 유리한 것이 아니다"의 근거로.
   3시드 → 5시드에서 상관이 소멸한 것을 반복 수의 교훈으로 한 문단.
2. **RQ2 답**: 예산이 늘수록 성능은 단조 상승, 위반은 감소, D\* 는 산 모양.
   "학습할수록 블랙박스가 된다"가 아니라 "재편 중일 때 가장 복잡하다". 같은
   예산·같은 점수에서 전술(치고 빠지기 vs 추격 격추)에 따라 D\* 가 3\~17 로 갈린
   것을 설명 비용의 진짜 원인으로 제시. 부록 F(격추 우선 적합도)로 이 전술이
   적합도 설계의 산물인지 확인한 결과를 붙임.
3. **RQ3 답**: BT-v3 처럼 규칙을 트리에 명시하면 위반율 0 이 보장되지만 성능을
   절반 내준다. 학습 정책은 셰이핑 벌점만으로 위반율을 BT-v2 의 45% 로 낮추면서
   성능도 올렸지만 0 은 아니다. "보장 vs 낮은 기대값"이라는 운용 선택 기준.
4. **혼합 다이얼의 위치**: 파레토 프론티어 아래. 성능은 순수 학습 정책을 넘지 못하고
   (α=0.75 가 근접) 설명가능성은 어느 쪽보다 나쁘다(D\* 11\~17). "지령 수준의 선형
   혼합은 두 계열의 약점을 합친다"로 정직하게. 감독형 혼합은 후속 연구.
5. **반론 선제 대응**
   * "BT 는 원래 트리라 유리" → 대리모델은 행동에만 적합, 동일 관측·지령공간, BT-v2 반례.
   * "D\* 는 트리에 유리한 지표" → F(4), D\*(0.90/0.99) 로 강건성, 절단 명시.
   * "BT 와 RL 에 들인 노력이 다르다" → **개발노력_기록.md** 수치 인용. 절대 순위가
     아니라 관계 형태가 주장임을 재확인.
   * "ES 는 RL 이 아니다" → 학습 기반 블랙박스 정책이라는 점이 논지의 핵심이며,
     알고리즘 명시. (PPO 결과가 있으면 부록 강건성으로.)

* A. 실험 설정 표 (results_auto.md 끝부분 그대로)
* B. 행동트리 전체 구조 (표 M1 아래 트리 목록)
* C. 셰이핑 포텐셜 가중치 (shaping.py 상단 상수)
* D. 전체 쌍별 검정표 (pairwise.csv)
* E. Tacview 재생 파일 목록 (results/replay/*.acmi) — 심사 시연용
* F. 강건성: '격추 우선' 적합도(격추승 +25, 시간종료승 +1, WEZ 가중 2배)로 학습한
  정책의 같은 표 (paper/results_robust.md, README 6.7). 결과: 격추 비율 중앙값이
  6% → 20% 로 올랐지만 시간종료승이 여전히 60\~96% — '치고 빠지기'는 적합도의
  산물이 아니라 이 환경에서 학습 정책이 발견하는 안정된 전술. 격추를 강하게 쫓은
  시드는 지면충돌 18%·위반율 0.128·D\*=17 로 세 축이 함께 악화. 성능–D\* 관계의
  형태(상관 없음, 전술 유형이 좌우)는 유지됨.
