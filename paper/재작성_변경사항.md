# 논문 재작성 변경 사항

## 0. 지금의 최종본 (2026-10-22, 15쪽판)

* `논문 최종본.hwpx`와 `논문 최종본.pdf`(저장소 최상위)가 최종 원고다. 대회 기준 "15쪽"에 맞춰 줄인 판이다.
  표지 1, 요약문 1, 본문 10(3–12쪽), 참고문헌 2(13–14쪽), 영문 초록 1(15쪽)로 15쪽이다. 그 뒤 16–17쪽은 별도 제출 서류인
  보안성 검토 의견서와 유사도 검사 결과서 양식이라 분량에 넣지 않았다. 한글 2018에서 열어 쪽수를 확인했다.
* `paper/본논문_재작성.md`는 같은 원고의 마크다운판이다. hwpx는 이 md를 팀의 10월 5일 hwpx 서식에 부어 넣어 만든다
  (`python -m dfxai.analysis.md_to_hwpx`, 한글 PDF 내보내기는 `python -m dfxai.analysis.hwp_export`).
* 줄이기 전의 41쪽판(10월 7일)은 git 커밋 560959e에, 팀의 10월 5일 원고는 커밋 fc37920에 있다. 41쪽판에만 있는 분석(민감도 표,
  6자유도 판정 표, 학습 예산 그림 등)은 필요하면 거기서 가져온다.

41쪽판에서 15쪽판으로 줄이며 바뀐 것은 다음과 같다.

| 항목 | 41쪽판 | 15쪽판 |
|---|---|---|
| 본문 | 약 3만 7천 자, 33쪽 | 약 9,300자, 10쪽 |
| 표 | 13개 | 3개(계열별 결과, 성능–설명 비용 상관, 제약 비용) |
| 그림 | 6개 | 1개(두 전술의 교전 궤적, 직접 만든 모의 환경의 교전 기록) |
| 각주 | 48개 | 22개 |
| 참고문헌 | 40건 | 20건 |

뺀 것은 연구 프레임워크 그림, 환경 설정 표, 행동트리 3종 표, 하이브리드 결합 방식 표(문장으로 바꿈), 성능–설명 비용 평면
그림, 학습 예산 그림, 전술 군집 표, 하이브리드 비교 표, 민감도 표, 6자유도 판정 표, 결과 종합 표다. 각 결과의 핵심 숫자는
본문 문장에 남겼다. 통계 기법(Wilson, Holm, Wilcoxon, Kruskal–Wallis, BIC 등)과 배경 문헌 일부(LIME, SHAP, 보상 분해,
근사 동적계획법, 3자유도 모델 선행연구 등)의 인용은 뺐다.

## 1. 첫 번째 지도 의견에 대한 반영

**"제목, 논문 목적, 연구 질문, 차별성이 일관되지 않다."** 네 가지를 한 줄기로 맞췄다.

| 항목 | 10월 5일 원고 | 지금 |
|---|---|---|
| 제목 | 설명가능성과 전투성능 트레이드오프 **분석** | 성능–설명가능성 트레이드오프 **검증** |
| 목적 | 세 축(성능·설명가능성·규칙 준수)을 통제 비교하여 관계를 정량 검증 | 트레이드오프가 **존재하는지 검증**하고 **설명 비용을 결정하는 요인**을 밝힘 |
| 연구 질문 | RQ1 관계, RQ2 학습량, RQ3 규칙 준수, RQ4 결합 방식 | RQ1 트레이드오프가 있는가, RQ2 설명 비용은 무엇이 정하는가, RQ3 하이브리드가 절충점이 되는가 |
| 차별성 | 공백 세 가지와 기여 네 가지(서로 다른 목록) | 2.3절 끝에서 RQ1–RQ3 각각에 하나씩 대응 |

**"인공지능이 작성한 틀이 그대로 보인다."** 굵은 소제목 문단, 가설 H1–H3 목록, "기여는 네 가지" 나열, 판정 표를 없애고
문단으로 썼다.

**"트레이드오프를 어떻게 분석하고 증명할 것인가."** 트레이드오프를 두 진술로 나눠 각각 검정하는 것을 원고의 중심에 두었다
(2.3절 개념, 3.2절 방법, 4.2절 결과). 기존 데이터로 새로 계산했으며 새 실험은 없다. 스크립트는
`dfxai/analysis/tradeoff_tests.py`, 결과는 `results/main/tradeoff_matrix.csv`와 `results/main/tradeoff_price_cv.csv`다.

| 검정 | 결과 |
|---|---|
| 연관성 (전체 282개 조건) | 성능 정의 × 설명 비용 정의의 모든 조합에서 ρ = −0.13–−0.01 |
| 연관성 (혼합 정책 제외 79개) | 학습 상대 성능에서만 약한 양의 상관(0.25), 보류 상대 성능에서는 반대(−0.22). 다중비교 보정 후 모두 유의하지 않음 |
| 제약 비용 (95% 기준 D\*) | 깊이 2 이하로 묶으면 0.15–0.34 손실, 깊이 3–5는 0.03–0.11, 깊이 6이면 학습 상대 기준 0.07만 남음 |
| 제약 비용 (90% 기준 D\*) | 깊이 5 이상이면 손실 0 |

## 2. 두 번째 의견(약점 점검)에 대한 반영

| 지적 | 반영 |
|---|---|
| 학습 모델이 정말 고성능인지 흔들린다 | 성능을 학습 상대·보류 상대·전원 대전 세 가지로 나눠 정의하고(3.2절) 모든 검정을 따로 했다. 4.1절 첫 결과로 "누가 강한가는 평가 상대에 따라 다르다"를 제시했고, 5.1절에 "고성능 학습 모델도 설명 가능하다고 주장하지 않는다"를 명시했다 |
| 학습 모델이 규칙 모델에서 출발했다 | 3.1절과 5.2절 한계에 "규칙 모델의 행동에서 출발해 갈라져 나간 모델"이라고 밝혔다 |
| D\*가 무엇을 재는지 고정되지 않았다 | D\*를 "행동 재현 간결성"으로만 부른다(2.2절). 90% 기준에서는 91%가 깊이 5 이하이고 95% 기준에서는 58%가 절단이라는 점을 3.2절에 먼저 적고, 표 4-1에 90% 기준 D\*를 함께 넣었다 |
| 하이브리드 확장은 규모가 작고, D\* 17도 90% 기준으로는 2–4다 | 3.1절에 3시드임을 적고, 4.4절에 90% 기준 값을 함께 써서 "결합이 늘린 것은 세부 행동의 복잡성"으로 한정했다 |
