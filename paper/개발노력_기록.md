# 개발 노력 기록

"BT 와 RL 에 들인 노력이 다르지 않느냐"는 지적은 반드시 나옵니다. 완벽히 공평할 수는
없지만, **기록해서 밝히는 것**과 침묵하는 것은 심사에서 천지 차이입니다. 이 문서는
논문 논의 절(반론 대응)과 부록의 원본입니다.

## 0. 먼저 밝혀야 할 것 — 개발 주체

이 프로젝트의 코드는 저자의 연구 설계·판단 아래 **LLM 코딩 에이전트(Claude, Anthropic)**
가 구현했습니다. 저자는 연구 질문·평가 설계·모델 정의·실패 시 방향 결정(예: BT 에
합류 회피 규칙을 넣을지, 학습 방식을 바꿀지)을 맡았고, 에이전트가 구현·실험 실행·
디버깅·문서화를 수행했습니다. 따라서 아래 "시간"은 사람의 작업 시간이 아니라
**에이전트 세션의 벽시계 시간**이며, 같은 도구가 BT 와 RL 양쪽을 만들었으므로
"한쪽에만 숙련된 개발자가 붙었다"는 비대칭은 없습니다.

> 대회 규정에 AI 도구 사용 고지 조항이 있는지 확인하고, 있으면 그 형식에 맞춰
> 논문에 명시하십시오. 없더라도 방법 절이나 감사의 글에 한 문장으로 밝히는 편이
> 안전합니다. 숨겼다가 드러나는 것이 가장 나쁜 경우입니다.

## 3. 튜닝 이력 (정직하게)

시도했다가 버린 것입니다. 논문에는 "X 를 시도했으나 Y 때문에 채택하지 않았다"로
한 줄씩 들어갑니다. 세부는 README 9절과 `rl/shaping.py` 상단.

**환경·지표 (이전 세션)**
* 뱅크 지령 한계 ±100° → ±180°. 행동이 포화되어 대리모델이 깊이 1에서 R²=0.98 을
  달성하는 함정 (README 4.2).
* 충실도 단순 평균 → 분산가중 평균. 상수 채널(스로틀 고정)이 지표를 부풀림.
* 단일 진영 평가 → 진영 교대 짝지은 설계. 자기대전 승률 0.59 → 0.500.

**BT (이 세션)**
* 정면 합류 회피 노드 추가. 순수추격만으로는 교전의 45~53% 가 정면 조우 공중충돌로
  끝났고, 그 상태로 학습하면 학습 정책이 배우는 것은 전술이 아니라 "들이받는 상대
  피하기"였음. 노드 수 v1/v2/v3 = 8/5/11 (회피 노드 3개 포함). 충돌 3~10% 로 감소.

**학습 정책 (이 세션) — 4회 시도**
1. 포텐셜 2.0 × Φ + 승패 적합도 → **원거리 회피 정책**으로 수렴 (거리 6~9 km, 피해 0,
   시간종료 100%). 포텐셜만으로 적합도 확보. 조치: 기하 항 근접 가중, 교전 지표 비중
   확대, 소극 무승부 벌점 −8.
2. 적합도 수정 후 무작위 초기화 → **여전히 회피** (100세대 정책 평균 거리 17 km).
   교전 시도의 기대 손실(격추 −30)이 회피(−9)보다 커서 ES 탐색이 실패. 조치:
   BT-v2 행동 복제로 초기화 (뱅크 R² 0.95, 복제본은 BT-v2 상대 0.50).
3. 복제 초기화 + 기존 ES 갱신 → **복제본 소실** (점수 0.50 → 200세대 0.00, 개체군
   붕괴). 순위 정규화 기울기의 잡음 성분 lr/(σ√pop) ≈ 0.06/세대가 무작위 행보를 유발.
   조치: 갱신 전후 θ 를 같은 시드로 평가하는 수용 검사, 후보당 교전 4 → 8.
4. 최종: 20시드 중 17개가 BT-v2 를 넘음 (300세대 0.716 ± 0.051 대 0.671).
   결과는 `paper/results_auto.md`, 요약은 README 6절.
* α 커리큘럼(후반 α≥0.9 만 학습) → 고정 격자 {0.25, 0.5, 0.75, 1.0}. 옛 방식에서는
  α=0.25 정책이 미학습 상태로 평가됨.
* 병렬 워커: 11 → 10, BLAS 스레드 1 고정. 병렬 확장이 2배에서 멈추는 것은 CPU 전력
  제한이라 코드로 해결 불가. 대신 시뮬레이터 핫루프를 8배 빠르게 함.

**혼합**
* 뱅크 채널 선형 평균 → 원형 평균. −170° 와 +170° 를 섞어 0° 를 내던 문제.

## 4. 논문에 들어갈 문장 (초안)

> 본 연구의 시뮬레이터·규칙 기반 모델·학습 파이프라인은 저자의 설계 아래 LLM 코딩
> 에이전트가 구현하였으며, 규칙 기반 모델과 학습 기반 모델은 동일한 도구·동일한
> 세션에서 개발되었다. 학습 기반 모델은 적합도 설계 실패 2회와 최적화 붕괴 1회를
> 거쳐 네 번째 시도에서 얻은 것으로, 규칙 기반 모델보다 약 10배의 개발·계산 시간이
> (확장 실험을 포함하면 그 이상)
> 투입되었다(부록 __). 따라서 두 계열의 절대적 성능 순위는 일반화할 수 없으며, 본
> 연구의 주장은 성능 순위가 아니라 성능–설명가능성 관계의 형태에 있다.
