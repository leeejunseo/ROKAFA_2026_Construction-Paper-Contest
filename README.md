## 0. 한눈에 보기

**연구 질문.** 1대1 기총 도그파이트에서 규칙 기반 AI(행동트리)·학습 기반 AI
(신경망)·둘의 혼합을 **같은 환경, 같은 관측, 같은 행동공간, 같은 잣대**로
비교하면, 전투성능과 설명가능성 사이에 어떤 관계가 있는가?

**핵심 결과 (5시드 본실험).**

1. 학습 정책은 규칙 기반 최강 모델(BT-v2)을 이긴다: 점수 **0.750 ± 0.022** 대
   0.671, 순수승률 0.79~0.88. 학습에 쓰지 않은 상대(BT-v3)에도 0.81~0.87.
2. 학습 예산이 늘수록 성능은 단조 상승(Spearman ρ=0.85, p<0.0001)하고 규칙
   위반은 절반으로 감소(0.096 → 0.045)했다.
3. **성능과 설명가능성 사이에 상관이 없다**: 67개 조건에서 점수–D\* 순위상관
   ρ=0.06 (p=0.62). "잘 싸우는 모델은 설명하기 어렵다"는 통념은 이 환경에서
   관측되지 않았다.
4. 설명가능성을 좌우한 것은 성능이 아니라 **학습 단계와 전술 유형**이었다.
   (a) 규칙 복제본(D\*=2)에서 출발한 학습 정책은 학습 초기에 급격히 복잡해졌다가
   (100세대 D\*=8.2) 수렴하면서 다시 단순해졌다(300세대 7.4). (b) 같은 예산·같은
   점수의 정책 5개가 D\*=3~17 로 갈렸고, 그 차이는 "한 번 쏘고 이탈" 대
   "끝까지 추격"이라는 전술 차이였다. (c) 규칙과 학습을 섞은 혼합 정책은 어느
   한쪽보다 설명하기 어려웠다(D\* 11~17).
5. 규칙 기반 모델 안에서는 안전규칙을 넣으면 위반율이 0 이 되는 대신 점수를
   절반 내준다(BT-v2 0.671 → BT-v3 0.329). 규칙준수–성능 트레이드오프는 규칙
   모델에서 뚜렷하고, 학습 정책은 셰이핑 벌점만으로 위반율을 BT-v2 의 45% 로
   낮추면서 성능도 올렸다.

## 1. 연구 배경과 질문

공중전 AI 는 AlphaDogfight(2020) 이후 강화학습이 숙련 조종사를 이기는 수준에
이르렀지만, 군 운용에서는 "왜 그렇게 기동했는가"를 사람이 확인할 수 있어야
한다. 여기서 흔히 "성능이 높은 모델은 블랙박스라 설명이 안 되고, 설명 가능한
규칙 모델은 약하다"는 트레이드오프가 전제처럼 이야기된다. 그러나 같은 과업에서
세 계열을 같은 잣대로 측정한 연구는 드물다. 이 연구는 그 전제를 **측정**한다.

* **RQ1.** 규칙 기반·학습 기반·혼합 모델의 전투성능과 설명가능성 사이에 어떤
  관계가 있는가?
* **RQ2.** 학습 예산(학습량)이 늘 때 두 축은 어떻게 함께 움직이는가?
* **RQ3.** 규칙 준수(안전 제약)는 이 관계에서 어떤 위치에 있는가?

기여는 세 가지다. (i) 모델 계열에 무관하게 행동 로그만으로 계산되는
설명가능성 지표(대리모델 최소 깊이 D\*), (ii) 초기조건 편향을 제거한 진영 교대
짝지은 평가 설계, (iii) 학습 예산 × 혼합계수 2차원 스윕으로 "점 몇 개"가 아닌
관계의 **형태**를 보인 것.

## 2. 실험 환경

### 2.1 왜 대회 환경이 아니라 별도 시뮬레이터인가

항공대 대회 프레임워크는 조종간·페달·스로틀을 직접 제어하는 고차원 입력이라
강화학습이 붙기 어렵고, 교전 1회에 수 초가 걸려 수만 회 학습이 불가능하다.
그래서 논문 실험용으로 **통제 가능한 축소 환경**을 만들었다. 대회 환경은 외부
검증·시연용으로 남긴다. 축소 환경의 설계 원칙 세 가지:

* **행동공간 추상화.** 정책은 `뱅크각 지령 · 하중배수(G) 지령 · 스로틀 지령`
  3채널만 낸다. 3자유도 점질량 모델의 자연스러운 입력이라 물리적으로 타당하고,
  세 모델 계열이 **같은 지령 공간**을 쓰게 되어 설명가능성 비교가 공정해진다.
* **관측 압축.** 원시 상태(위치·속도 12차원) 대신 교전기하 20차원(거리, 기수-시선
  각 ATA, 애스펙트각 AA, 접근률, 고도차, 비에너지차, 잔여 HP, 경과시간 등)을
  쓴다. 도그파이트는 이 좌표계에서 사실상 완전히 기술된다.
* **혼합 다이얼.** `a = (1−α)·a_BT + α·a_RL` 한 줄로 세 계열을 잇는다. α 를
  관측에 포함시켜 학습하면 **정책 하나가 모든 α 에서 동작**한다.

### 2.2 시뮬레이터

* 기체: F-16급 공개 제원의 3자유도 점질량 모델(질량 9,300 kg, 익면적 27.87 m²,
  CL_max 1.6, 해면 최대추력 106 kN, 구조한계 9 G). 양력 한계와 구조 한계 중 작은
  값이 가용 G 가 되어 **코너속도가 자연스럽게 창발**한다. 뱅크·G·스로틀은 1차
  지연(0.35/0.30/1.2 s)으로 지령을 따른다.
* 적분: 명시적 오일러 0.05 s, 제어주기 0.2 s(5 Hz), 교전 120 s.
* 기총 WEZ: 거리 120~1,200 m 이고 보어사이트 이탈각(ATA)이 명중 원추 안이면
  25 HP/s 피해. 원추 반각은 대회 규정처럼 3° 에서 10° 로 시간에 따라 넓어진다.
* 종료: 상대 HP 0 → 격추승, 고도 0 → 지면충돌패, 거리 60 m 미만 → 공중충돌
  (양측 패 = 무승부), 120 s → 잔여 HP 비교(같으면 무승부).
* 초기조건: 거리 1.5~3.5 km, 고도 3~5 km, 속도 180~260 m/s 를 양측 동일하게 두고
  각자의 기수방위만 무작위. 잔여 편향은 진영 교대(§5.1)로 상쇄.
* 속도: 교전 1회 약 0.02 s(단일 코어). 의존성은 numpy·pandas·scipy·scikit-learn·
  matplotlib, 행동 복제 초기화에만 torch.

전체 수치는 `paper/results_auto.md` 부록 A(config.py 스냅샷)에 있다. 값을
바꾸면 부록도 자동으로 바뀐다.

## 3. 비교 모델

세 계열 모두 **관측 20차원 → 지령 3차원**의 같은 인터페이스를 쓴다.

### 3.1 규칙 기반: 행동트리(BT) 3종

전술을 창작하지 않고 BFM(기본전투기동) 교범의 표준 전술만 옮겼다. 순수추격·
리드추격, 양력벡터 지향, 하드덱 이탈 회복, 정면 합류(merge) 회피. 실제
Selector/Sequence 노드로 만들어 노드 수를 셀 수 있다. 세 버전은 성숙도 사다리가
아니라 **서로 다른 교리**다.

| 모델 | 노드 | 교리 | 점수(상대 2종 평균) | 위반율/스텝 |
|---|---|---|---|---|
| BT-v1 수평 추격 | 8 | 수직면을 쓰지 않는 고정 4 G 수평 추격 | 0.241 | 0.005 |
| BT-v2 3차원 최대선회 | 5 | 양력벡터를 시선으로 돌리며 최대 G·최대 추력 | **0.671** | 0.100 (하드덱 0.049, 과G 0.044) |
| BT-v3 3차원+안전규칙 | 11 | v2 + 하드덱 회복, 8 G 자율제한, 사격 시 리드추격 | 0.329 | **0.008** (하드덱·과G 0) |

세 BT 모두 최우선 노드로 `merge_avoidance`(거리 1 km 이내·접근률 200 m/s
초과·서로 정면이면 상대 반대쪽으로 75° 뱅크)를 공유한다. 이 노드가 없던 초기
설계에서는 순수추격 둘이 정면에서 서로를 향해 직진하다 **교전의 45~53% 가
공중충돌**로 끝났다(§8.1).

### 3.2 학습 기반: 신경망 정책 (MLP, 진화전략)

* 구조: 20-32-32-3 tanh MLP, 파라미터 1,827개. 순전파는 numpy.
* **초기화: BT-v2 행동 복제.** BT-v2 가 BT-v1/v2/v3 와 싸운 로그 161,694 샘플에
  MLP 를 회귀시켜(뱅크 채널 R² 0.95) 얻은 가중치에서 출발한다. 복제본은 BT-v2
  상대 0.50, BT-v3 상대 0.83 으로 원본과 거의 같게 싸운다. 무작위 초기화가
  실패한 경위는 §8.2.
* **학습: OpenAI-ES 변형.** 미러 샘플링, 순위 정규화, σ 0.05, lr 0.01, 개체군 32,
  후보당 8교전(α 격자 {0.25, 0.5, 0.75, 1.0} × 2시드, 상대 BT-v1/v2 교대), 300세대.
  여기에 **갱신 수용 검사**를 더했다: 갱신 전후의 정책을 같은 시드로 평가해
  나빠지면 갱신을 거부하고 보폭을 줄인다(§8.3). 시드당 28~35분, 수용률 약 58%.
* **적합도(에피소드 스칼라)**: 0.2 × (가한 피해 − 받은 피해) + 0.5 × WEZ 체류초
  + 종료보상(격추승 +10, 시간종료승 +5, 격추패 −10, 시간종료패 −5, 공중충돌 −5,
  지면충돌 −15) + 0.5 × 평균 포텐셜 − 3 × (하드덱+과G 위반율) − 8 × [양측 무피해
  시간종료]. 포텐셜 Φ 는 ATA·AA·에너지 항에 근접 가중(사거리 밖 지수 감쇠)을 곱한
  것으로, 포텐셜 기반 셰이핑(Ng, Harada & Russell 1999)의 형태라 최적정책을 바꾸지
  않는다. 이 설계에 이르기까지의 실패는 §8.2.
* **학습 예산 축**: 체크포인트 0(복제본), 100, 200, 300세대. 학습 시드 5개.
* α=1.0 정책은 MLP 만 실행하는 블랙박스다. "초기화를 BT 에서 했다"는 사실은
  방법 절에 명시하되, 학습 기반 모델이라는 정의는 유지된다.

### 3.3 혼합: BT + 학습 정책

`a = (1−α)·a_BT-v2 + α·a_RL`. 뱅크 채널은 각도(±1 = ±180°)라 **원형 평균**
(sin/cos 가중합의 atan2)을 쓴다. 선형 평균은 −170° 와 +170° 를 섞어 0° 를 내어
양력벡터를 정반대로 돌린다. α ∈ {0.25, 0.5, 0.75}. α 는 관측 벡터의 마지막
원소로 정책에 들어가므로 학습 정책 하나가 모든 α 에서 동작한다.

## 4. 세 평가축

### 4.1 전투 성능

주 지표는 **점수** = 승 1 · 무 0.5 · 패 0. 무승부가 적지 않으므로(BT-v2 자기대전
49%) 무승부 제외 **순수승률**과 **종료 사유 분포**(격추/시간종료/지면충돌/
공중충돌)를 반드시 함께 보고한다. 한쪽만 쓰면 결론이 무승부 처리 방식에
의존한다는 지적을 받는다. 보조: WEZ 체류시간, 피해량, 생존시간.

### 4.2 설명가능성: 대리모델 최소 깊이 D\*

정책이 남긴 (관측, 행동) 궤적에 깊이 d 의 결정트리 회귀모델을 적합하고, 테스트
셋에서 원 정책의 행동을 재현한 정도(R², 채널 분산가중 평균)를 충실도 F(d) 라
한다. **D\* = F(d) ≥ 0.95 를 처음 만족하는 최소 깊이.** 작을수록 단순한 규칙으로
설명 가능하다. 깊이 16까지 검사해 미달이면 17로 **우측 절단**한다(생존분석의
censoring 과 같이 취급하며 논문에 명시). 보조 지표로 D\*(0.90), D\*(0.99), 깊이
4 고정 충실도 F(4)를 함께 낸다.

왜 이 지표인가: SHAP·보상분해 같은 기법은 특정 모델 계열에만 적용되지만, 이
지표는 **행동 로그만 있으면 계산**되어 BT·MLP·혼합에 완전히 동일하게 적용된다.
"BT 는 원래 트리라 유리하다"는 반론에는 두 가지로 답한다. 대리모델은 정책의
내부 구조가 아니라 관측된 행동에만 적합하고, 세 계열이 같은 관측·지령 공간을
쓴다. 실제로 BT-v2 는 노드 5개짜리 트리지만 arctan2 기반 연속 함수라 D\*=4 인
반면, 그것을 복제한 MLP 는 D\*=2 다 — 트리 구조가 유리한 것이 아니다.

지표 설계에서 잡은 함정 둘. **행동 포화**: 뱅크 지령 한계를 ±100° 로 두면 출력이
상시 포화되어 사실상 이진값이 되고 대리모델이 깊이 1로 R²=0.98 을 달성해
버린다. ±180° 로 넓혔다. **상수 채널**: 스로틀을 항상 최대로 두는 정책은 해당
채널 분산이 0이라 R²=1 이 되어 단순 평균이 지표를 부풀린다. 분산가중 평균으로
고쳤다.

주의: D\* 는 시드 간 분산이 크다(같은 예산에서 표준편차 5~7). 논문에서는 D\*
하나로 주장하지 말고 F(4)·충실도 곡선과 나란히 두어 방향이 일치함을 보인다.

### 4.3 규칙 준수

적분 스텝당 위반율. 하드덱(최저고도 1,000 m) 침범, 과G(8 G 초과), 최소이격
(150 m) 침범. 주관적 해석이 개입하지 않는 객관 지표다.

## 5. 실험 설계

### 5.1 진영 교대 짝지은 평가

처음에는 같은 정책끼리 붙였는데 승률이 0.59 가 나왔다. 특정 시드의 초기조건이
청군에 유리했던 것이다. 그래서 **같은 시드로 청/홍을 바꿔 한 번 더** 싸우게
했고, 이후 자기대전 점수는 정확히 0.500 이 됐다(BT-v2, 100시드 × 2). 이 검증
자체를 논문 방법 절에 한 문장으로 넣으면 설계가 편향 없음을 보이는 근거가 된다.

### 5.2 통계

같은 시드의 두 판은 독립이 아니므로 **시드 단위로 평균한 뒤** 그 값들을
표본으로 삼는다. 점수의 신뢰구간은 Wilson 95%, 조건 간 비교는 같은 시드를
공유하므로 **대응표본 Wilcoxon**, 다중비교는 **Holm-Bonferroni**, 동전던지기
(0.5) 대비 순수승률은 이항검정. 조건 간 순위상관은 Spearman ρ 와 Kendall τ
(D\* 에 절단값이 있어 순위 기반이 적절).

### 5.3 조건 격자

* 규칙: BT-v1, v2, v3 (3)
* 학습·혼합: 예산 {0, 100, 200, 300} × α {0.25, 0.5, 0.75, 1.0} × 학습 시드 5
  (예산 0 은 복제본 하나) = 64
* 상대: BT-v2(학습에 사용) 와 **BT-v3(보류 상대, 학습 미사용)** 각 100시드 × 진영 2
* 총 67조건 × 400교전 = **26,800교전** (본실험 21,200 + 재평가 포함)

조건 이름 규칙(분석 코드가 파싱하므로 바꾸지 말 것): `BT-v2`,
`RL-s0-b300-a1.00`(학습시드 0, 예산 300, α 1.0 = 순수 학습), `HYB-s1-b200-a0.50`.

### 6.3 예산에 따른 설명가능성 — 산 모양 (RQ2)

D\* 는 예산에 단조가 아니다. 복제본 2 → 100세대 8.2 → 200세대 7.8 → 300세대 7.4.
F(4) 도 0.975 → 0.929 → 0.933 → 0.933 으로 같은 형태. 예산–D\* 상관은 ρ=−0.01
(p=0.98). 해석: 복제본(규칙과 거의 같은 행동)에서 벗어나 새 전술로 재편되는
학습 초기에 행동이 가장 복잡해지고, 수렴하면서 다시 단순해진다. 성능은 이
구간에도 계속 오른다(0.634 → 0.750). **설명 비용은 성능의 함수가 아니라 학습
단계의 함수**였다.

### 6.4 같은 예산, 다른 전술 — 설명가능성 차이의 정체

300세대 순수 학습 정책 5개(점수 0.729~0.785)의 종료 사유와 D\*:

| 학습시드 | 점수 | 격추 비율 | 시간종료 비율 | WEZ 초 | D\*(0.95) | F(4) |
|---|---|---|---|---|---|---|
| s0 | 0.729 | 0.02 | 0.96 | 0.34 | **3** | 0.966 |
| s3 | 0.733 | 0.06 | 0.92 | 0.62 | 6 | 0.931 |
| s2 | 0.746 | 0.06 | 0.93 | 0.59 | 6 | 0.924 |
| s4 | 0.755 | 0.14 | 0.85 | 0.87 | 5 | 0.945 |
| s1 | 0.785 | **0.35** | 0.60 | 1.94 | **17 (절단)** | 0.898 |

두 전술이 갈린다. s0 은 초반에 한 번 스치듯 쏴서 HP 우위를 만든 뒤(대표 교전에서
HP 100:91) 상대 원과 어긋난 원을 돌며 다시는 붙지 않고 **시간종료 HP 우위**로
이긴다 — 규칙상 합법이고 대회 규정과 같지만 '치고 빠지기'다. s1 은 끝까지 붙어
**격추**로 이긴다. 격추 비율이 높을수록 D\* 가 커진다. 설명가능성 차이는 성능이
아니라 **전술의 종류**에서 왔다. 논의 절의 핵심 문단이며, 대표 교전 그림
`paper_figs/fig_traj_RL-s0-b300-a1.00.png` 과 Tacview 파일이 이 전술을 보여준다.
'치고 빠지기'가 적합도 설계의 산물인지는 부록 강건성 실험(§6.7)으로 확인한다.

### 6.5 혼합 정책

| α | 예산 100 | 200 | 300 |
|---|---|---|---|
| 0.25 점수 / D\* | 0.640 / 17 | 0.613 / 14.6 | 0.638 / 10.8 |
| 0.50 점수 / D\* | 0.649 / 15 | 0.624 / 15.8 | 0.632 / 14.8 |
| 0.75 점수 / D\* | 0.675 / 15.8 | 0.702 / 17 | 0.715 / 13.4 |
| 1.00 점수 / D\* | 0.634 / 8.2 | 0.721 / 7.8 | 0.750 / 7.4 |

혼합은 성능에서 순수 학습 정책을 넘지 못하고(α=0.75 가 근접), 설명가능성에서는
**어느 쪽보다 나쁘다**(D\* 11~17, 대부분 절단). 서로 다른 두 정책의 지령을 섞은
행동은 어느 한쪽보다 규칙으로 기술하기 어렵다. "혼합이 새로운 절충점을
만드는가"에 대한 답은 이 환경에서 **아니오**다. 다만 이것은 지령 수준의 선형
혼합에 대한 결론이며, 규칙이 학습 정책을 감독하는 다른 형태의 혼합은 후속 연구.

### 6.6 규칙 준수 (RQ3)

| 모델 | 점수 | 하드덱 | 과G | 위반 합계 |
|---|---|---|---|---|
| BT-v2 | 0.671 | 0.049 | 0.044 | 0.100 |
| BT-v3 (안전규칙) | 0.329 | 0.000 | 0.000 | 0.008 |
| 학습 정책 300세대 (5시드 평균) | 0.750 | 0.000~0.013 | 0.028~0.037 | 0.045 |

규칙 모델에서는 안전규칙이 위반을 0 으로 만들지만 성능을 절반 내준다. 학습
정책은 적합도의 약한 벌점(−3 × 위반율)만으로 하드덱 위반을 거의 없애고 과G 도
줄이면서 성능은 올렸다(예산–위반율 ρ=−0.37, p=0.002). 단 0 은 아니다 —
"규칙을 트리에 명시하면 0 이 보장되고, 학습으로는 0 에 가까워질 뿐"이라는
대비가 논의 절의 재료다.

### 6.7 부록 강건성: 격추 우선 적합도

§6.4 의 '치고 빠지기'가 적합도 설계(시간종료승 +5)의 산물인지 보기 위해
격추승 +25, 시간종료승 +1, WEZ 가중 2배인 `kill_first` 프리셋으로 2시드를 다시
학습해 순수 학습 정책만 평가한다. 결과는 `paper/results_robust.md`. (이 문서
작성 시점에 실행 중 — 완료되면 이 절과 논문 골격에 반영.)

### 6.8 정성적 예시: 깊이 3 규칙

`paper/results_auto.md` '정성적 예시' 절에 각 정책을 깊이 3 회귀트리로 근사한
규칙이 있다. BT-v3 의 트리는 `h_own ≤ 0.23`(≈1,380 m = 하드덱 + 400 m) → 날개

## 7. 논의 재료

* **RQ1 답.** 트레이드오프는 관측되지 않았다(ρ≈0). 규칙 모델(D\* 1~5)과 학습
  정책(3~17)의 범위가 겹치며, 가장 강한 정책(s1, 0.785)이 가장 복잡하지만 두
  번째로 강한 정책(s4, 0.755)은 BT-v3 와 같은 D\*=5 다.
* **RQ2 답.** 예산이 늘면 성능은 단조 상승, 위반은 단조 감소, 설명 비용은 초기에
  올랐다가 내려온다. "학습할수록 블랙박스가 된다"가 아니라 "재편 중일 때 가장
  복잡하다".
* **RQ3 답.** 규칙 모델은 안전을 명시해 0 을 보장하되 성능을 잃고, 학습 정책은
  벌점으로 0 에 가까워지되 보장은 없다. 운용 요구가 "보장"이면 규칙, "낮은
  기대값"이면 학습이라는 선택 기준이 도출된다.
* **반론 대응.** "BT 는 트리라 유리" → 복제 MLP(D\*=2) < BT-v2(D\*=4). "D\* 는
  트리에 유리한 지표" → F(4)·D\*(0.90)·충실도 곡선이 같은 방향. "BT 와 RL 에
  들인 노력이 다르다" → `개발노력_기록.md` 의 시간표(학습 정책에 약 4배). "ES 는
  RL 이 아니다" → 학습 기반 블랙박스라는 점이 논지의 핵심이고 알고리즘을 명시.
  "시드 3 결과와 다르다" → 그것이 바로 반복 수의 교훈.
* **한계를 먼저 쓴다.** 예시 문장: "본 연구의 규칙 기반 모델과 학습 기반 모델은
  동일 팀이 제한된 예산 내에서 구현한 것이므로 절대적 성능 순위는 일반화할 수
  없다. 본 연구의 주장은 순위가 아니라 관계의 형태에 있다."

## 8. 개발 이력 — 실패와 수정

심사위원이 가장 신뢰하는 것은 실패를 숨기지 않은 기록이다. 방법 절 또는 부록에
한 문단씩 쓴다. 폐기된 실행은 전부 `results/es_v*` 에 보관돼 있다.

### 8.1 BT 끼리 붙이면 절반이 공중충돌

순수추격만 있는 BT 둘이 정면에서 만나면 서로를 향해 직진하다 60 m 안으로
들어와 교전의 45~53% 가 공중충돌(양측 패)로 끝났다. 이 상태로 학습하면 학습
정책이 배우는 것은 전술이 아니라 "들이받는 상대 피하기"다. 실제 BFM 에서 합류
시 측방 이격 유지는 기본 규칙이므로 세 BT 모두에 `merge_avoidance` 노드를 최우선
으로 넣었다. 충돌은 3~10% 로 떨어졌고 BT-v2 대 BT-v3 교전의 58% 가 격추로 끝난다.

### 8.2 학습 정책이 도망가는 법을 배웠다 (보상 해킹, 2회)

**1차.** 적합도 = 2.0 × 평균 포텐셜(ATA·AA·사거리·에너지) + 승패. 400세대
학습한 정책은 **상대와 6~9 km 떨어져 고도 5~8 km 로 올라가 기수만 상대 쪽으로
둔 채 도망**다녔다. WEZ 0초, 피해 0, 시간종료 100%. 원거리에서도 ATA 가 작고
에너지 우위가 커서 포텐셜만으로 적합도 1.5~2.0 을 챙길 수 있었다. 점수 0.38 은
"무승부 77% × 0.5" 였고 예산을 늘려도 아무것도 변하지 않았다. 조치: 기하 항에
근접 가중(사거리 밖 지수 감쇠), 포텐셜 비중 2.0 → 0.5, 피해·WEZ 비중 확대, 양측
무피해 시간종료 −8. 또 α 커리큘럼(후반 α≥0.9 만 학습)이 α=0.25 정책을 미학습
상태로 남겨 점수 0.14 가 나온 것을 발견하고 매 세대 α 격자를 고정으로 바꿨다.

**2차.** 적합도를 고쳐도 무작위 초기화에서는 **여전히 회피**(100세대 정책 평균
거리 17 km). 교전을 시도하면 BT-v2 에게 격추당해 −30, 도망가면 −9 이므로 ES
탐색이 싸우는 정책을 발견할 확률이 사실상 0 이다 — 희소·고분산 보상에서
진화전략의 알려진 한계. 조치: **BT-v2 행동 복제 초기화**(§3.2). 복제본은
원본과 거의 같게 싸우고, 학습 예산 축은 "복제본에서 얼마나 멀어졌나"가 된다.

### 8.3 ES 가 복제본을 지웠다

복제 초기화 후 기존 ES 갱신(σ 0.05, lr 0.02)을 돌리자 점수가 0.50 → 100세대
0.41 → 200세대 0.00 으로 무너지고 개체군 전체가 같은 적합도로 붕괴했다. 순위
정규화 기울기는 신호가 약해도 크기가 일정하므로 가중치가 매 세대 lr/(σ√pop) ≈
0.06 씩 **무작위 행보**를 하고, 가중치 크기(≈0.3)에 비해 커서 100세대면 복제본이
지워진다. 무작위 초기화 때는 잃을 것이 없어 드러나지 않던 문제. 조치: 갱신
전후의 정책을 같은 시드로 평가해 나빠지면 거부하는 **수용 검사**(대응 비교라
잡음이 작음), 후보당 교전 4 → 8. 10세대 시험에서 수용률 50%, 복제본 유지 확인.

### 8.4 그 밖에

* 하이브리드 뱅크 혼합을 선형 평균에서 원형 평균으로(§3.3).
* 병렬 학습이 느린 원인은 코드가 아니라 CPU(i5-1235U, P코어 2 + E코어 8, 15 W)
  의 전력 제한이었다. 워커를 늘려도 처리량이 2배에서 멈춘다. 대신 시뮬레이터
  핫루프를 numpy 스칼라 호출에서 `math` 연산으로 바꿔 8배(0.2 → 0.02 s/교전)
  빠르게 했다. 결과는 반올림 수준에서 동일함을 참조 궤적으로 확인했다.
* 학습이 됐는지는 셰이핑 적합도가 아니라 **`dfxai.rl.monitor` 의 실제 점수
  곡선**으로 판단한다. 적합도는 1차 시도처럼 오르면서도 아무것도 안 배울 수 있다.

## 9. 한계

* 3자유도 점질량 모델: 받음각·옆미끄럼·실속/스핀·무장 탄도를 모사하지 않는다.
  Tacview 재생에서 기체가 항상 속도벡터를 향하는 것은 이 가정 때문이다. 결론은
  이 모델 범위 안에서만 유효하다.
* 1대1 WVR 기총, 고정 BT 상대 2종. 자가대전·BVR·다수기는 후속 연구.
* 학습 정책은 BT-v2 복제본에서 출발했으므로 "규칙과 무관하게 학습한 정책"이
  아니다. 이는 설계상 선택이며, 그 덕에 "규칙과 같은 행동에서 출발해 갈라진다"는
  실험이 가능했다.
* D\* 의 시드 간 분산이 크다. 5시드로도 D\* 단독으로는 약하므로 F(4)·충실도
  곡선을 병기한다.
* 사람이 정책의 다음 기동을 예측하는 이해도 실험은 하지 않았다. D\* 는 이해도의
  대리 지표다.
* 규칙 모델과 학습 모델을 같은 도구(LLM 코딩 에이전트)가 만들었다. 노력의
  절대량은 `개발노력_기록.md` 에 있고, 절대 성능 순위는 일반화하지 않는다.

## 10. 재현 절차

```bash
pip install -r requirements.txt          # torch 는 (1a) 에만 필요

# (0) 파이프라인 검증 (합성 데이터 — 수치를 논문에 쓰면 안 됨)
python -m dfxai.experiments.make_synthetic --outdir results/dryrun
python -m dfxai.analysis.report --outdir results/dryrun

# (1a) 행동 복제 초기화 (1분)
python -m dfxai.rl.pretrain_bc --teacher 2 --out results/es/bc_init.npz

# (1) ES 미세조정, 학습 시드 5개 (시드당 약 30분)
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
for s in 0 1 2 3 4; do
  python -m dfxai.rl.train_es --generations 300 --pop 32 --episodes 8 \
         --sigma 0.05 --lr 0.01 --workers 10 --checkpoint-every 50 \
         --seed $s --tag seed$s --init results/es/bc_init.npz
done
# (1b) 다른 터미널에서 학습 뷰어: results/es/monitor.html 을 브라우저로
python -m dfxai.rl.monitor --esdir results/es --generations 300 --watch 60

# (2) 본실험 (약 40분)
python -m dfxai.experiments.run_eval \
       --ckpts results/es/bc_init.npz \
               results/es/ckpt_seed{0,1,2,3,4}_gen00{100,200,300}.npz \
       --alphas 0.25 0.5 0.75 1.0 --opponents 2 3 \
       --n-seeds 100 --workers 10 --outdir results/main

# (3) 분석·그림·문서
python -m dfxai.analysis.report  --outdir results/main
python -m dfxai.analysis.figures --outdir results/main --esdir results/es
python -m dfxai.analysis.paper   --outdir results/main --esdir results/es --out paper/results_auto.md

# (4) Tacview 재생 파일 (논문 그림과 같은 seed)
python -m dfxai.viz.replay --from-run results/main --red bt:3

# (5) 부록 강건성: 격추 우선 적합도
for s in 0 1; do
  python -m dfxai.rl.train_es --generations 300 --pop 32 --episodes 8 --sigma 0.05 --lr 0.01 \
         --workers 10 --checkpoint-every 50 --seed $s --tag seed$s \
         --init results/es/bc_init.npz --fitness kill_first --outdir results/es_killfirst
done
python -m dfxai.experiments.run_eval --ckpts results/es_killfirst/ckpt_seed{0,1}_gen00{100,200,300}.npz \
       --alphas 1.0 --opponents 2 3 --n-seeds 100 --workers 10 --outdir results/robust
python -m dfxai.analysis.report --outdir results/robust
python -m dfxai.analysis.paper  --outdir results/robust --esdir results/es_killfirst --out paper/results_robust.md
```

노트북급 CPU 에서 전체 약 4.5시간. `config.py` 값을 바꾸면 `manifest.json` 과
부록 A 가 자동으로 바뀌므로 재현성은 유지된다.

### 10.1 Tacview 로 교전 보기

`DogfightEnv(record_traj=True)` 가 매 0.1초 두 기체의 위치·속도·뱅크·경로각·G·
HP 와 이벤트를 기록하고, 이를 Tacview 공개 포맷 **ACMI 2.2** 로 내보낸다. 무료판
